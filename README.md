# qr-copy-paste
C# .NET 8 WinForms tray app that monitors the clipboard and, on new text, shows a QR code overlay at the bottom-right of the active monitor. Single-instance, DPI-aware, throttles duplicates, auto-dismisses, and replaces on new copy. Tray: Show Last, Pause/Resume (Ctrl+Shift+Q), Settings, Exit. Settings in %AppData% JSON. Uses QRCoder.
